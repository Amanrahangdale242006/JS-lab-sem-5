# Aman Rahangdale — Portfolio

## Run locally
1. Extract the complete ZIP.
2. Keep `index.html`, `Aman_Rahangdale_Resume.pdf`, and the `assets/` folder together.
3. Open `index.html` in a browser, or use VS Code + Live Server.

## Included
- Responsive single-page portfolio built with HTML, CSS and JavaScript (dark and light themes follow your device)
- Education, skills, six projects, UI/UX internship experience and contact links
- Five course certificates and the Maincrafts internship certificate in `assets/` (click a certificate to enlarge it)
- Resume as PDF and Word (.docx)

## Before sharing
- Replace the orange dashed placeholders in `index.html`: Interview Scheduling System description and tech stack, and Class X / XII details. Search the file for `class="ph"`.
- Delete the "Draft" note at the bottom of the Contact section once everything is filled in.
- Fonts load from Google Fonts, so an internet connection gives the intended look; offline it falls back to system fonts.
